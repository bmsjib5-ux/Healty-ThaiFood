# AmHealty

แอป React Native + Expo + TypeScript ตามแนวคิด UI ภาษาไทยที่ออกแบบไว้: สีเขียวธรรมชาติ ครีม และการ์ดสารอาหารสีอ่อน

เขียนใหม่จากแนวคิดฟีเจอร์ OpenNutriTracker ไม่ได้ fork หรือคัดลอก source code ของโครงการนั้น

## เริ่มใช้งาน

ต้องมี Node.js 22.13+ และ npm

```powershell
cd D:\Chibi_Rigged\nutri-thai
npm install
npm run web
```

สำหรับมือถือ: `npm start` แล้วใช้ Expo Go รุ่นที่รองรับ Expo SDK 57 สแกน QR (คอมพิวเตอร์กับมือถืออยู่เครือข่ายเดียวกัน) หาก Expo Go ยังไม่รองรับ SDK นี้ ต้องใช้ development build ที่ตรงรุ่น

Android emulator: `npm run android` (ต้องติดตั้ง Android Studio/SDK ก่อน)

iOS simulator ต้องใช้ macOS/Xcode ส่วนการ build สำหรับ App Store ต้องมีบัญชีและ signing ของเจ้าของแอป

## ฟีเจอร์รุ่นแรก

- วันนี้: ยอดแคลอรีและสารอาหารรวมจากรายการจริง วงแหวนความคืบหน้า และเปลี่ยนวันที่ดูประวัติ
- อาหาร: ค้นหาอาหารไทย/อาหารทั่วไป 12 รายการ กรองหมวด รายการโปรด เลือกกรัมหรือหน่วยบริโภค และแยก 4 มื้อ
- ลบรายการอาหารและคำนวณยอดใหม่
- เพิ่ม/ลดน้ำดื่มครั้งละ 250 มล. แยกตามวันที่
- บันทึกน้ำหนักรายวัน กราฟช่วง 7/30/90 วัน น้ำหนักเป้าหมาย และลบรายการ
- โปรไฟล์: ตั้งชื่อ เป้าพลังงาน สารอาหาร น้ำดื่ม และน้ำหนัก
- เก็บข้อมูลด้วย AsyncStorage บนมือถือ และ localStorage บนเว็บ ข้อมูลแยกกันตามอุปกรณ์/เบราว์เซอร์
- ไม่มีบัญชีผู้ใช้ ไม่มี backend และไม่ต้องใส่ API key

## ตรวจสอบและ build

```powershell
npm test
npm run typecheck
npm run build:web
npm run preview
```

พรีวิว static: http://localhost:8081

หากต้องปิด telemetry ของ Expo ในสภาพแวดล้อมจำกัดสิทธิ์ ให้ตั้ง `$env:EXPO_NO_TELEMETRY="1"` และ `$env:EXPO_OFFLINE="1"` ก่อน build; ไม่กระทบการทำงานของแอป

## ขอบเขต

ข้อมูลอาหารเป็นค่าประมาณสำหรับเริ่มต้นทดสอบ ไม่ใช่ฐานอาหารไทยที่ตรวจสอบทางโภชนาการแล้ว ค่าเป้าหมายเริ่มต้นเป็นตัวอย่างที่ผู้ใช้แก้ได้ ไม่ใช่การคำนวณเฉพาะบุคคล

ยังไม่มีสแกนบาร์โค้ด วิเคราะห์รูปอาหาร AI เชื่อมฐานข้อมูลภายนอก บัญชีผู้ใช้ สำรอง/ซิงก์ข้อมูล หรือ APK/IPA สำหรับเผยแพร่

ข้อมูลใน AsyncStorage/localStorage ไม่ได้เข้ารหัสโดยแอป การล้าง storage หรือถอนการติดตั้งทำให้ข้อมูลหาย อย่าใช้เป็นสำเนาประวัติสุขภาพเพียงแห่งเดียว

## โครงสร้าง

- `App.tsx` หน้าจอและการเชื่อม state/storage
- `src/model.ts` อาหาร การคำนวณ วันที่ และ validation ข้อมูล
- `src/styles.ts` สีและสไตล์ร่วม
- `tests/model.test.mjs` ทดสอบการคำนวณ การแยกวัน น้ำหนัก และข้อมูลบันทึก
